# Responsive Camera Probe, Auto-Calibration & Mobile Companion Bundle

기존 `v0.6.0`(`phase-05-v0.6.0`)의 1~5단계 통합 기능(두 카메라 실시간 수신, YOLO11n·ByteTrack 2D 추적, 스테레오 3D 삼각측량, 3D 충돌 위험 분석·경고, 통합 관제 대시보드·기록·재생)을 유지하면서,
**카메라 지원 범위 비동기 조회 및 설정 자동 복구 개선**, **체커보드 없는 자동 보정 및 상·하 카메라 배치 지원**, **최신 릴리스 내 모바일 송출 앱(Android APK·iOS IPA·Xcode 프로젝트) 통합 첨부**를 반영한 업데이트입니다.
기존 `v0.1.0`–`v0.4.0`, `phase-02-v0.5.0`, `phase-05-v0.6.0` 태그와 릴리스는 그대로 보존됩니다.

> **실험용 / 실제 비행 미검증 안내**
> - 이 릴리스의 3~5단계 및 자동 보정 기능은 단위 테스트, 알려진 카메라 배치·정답 좌표를 갖는 합성 데이터, 헤드리스 GUI 통합 테스트 및 GitHub Actions CI(Windows·macOS·모바일)로 검증되었습니다.
> - **실제 드론 2대 비행, 실외 환경에서의 스테레오 보정, 실제 비행 중 위치 오차 및 충돌 경고 성능은 아직 현장 실험 전(미검증)입니다.**
> - 본 프로그램은 실험용 보조 시스템이며 실제 비행 안전을 보장하지 않고 드론 자동 제어 기능을 포함하지 않습니다.

## 첨부 파일

- `DroneCollisionDetection-v0.6.1-macos-arm64.dmg`: Apple Silicon (M1 이상)
- `DroneCollisionDetection-v0.6.1-macos-x64.dmg`: Intel Mac
- `DroneCollisionDetection-v0.6.1-windows-x64.exe` / `.zip`: Windows 10/11 x64 (CPU 전용 AI)
- `phase-01-camera-stream-v0.6.1.zip`: 개발용 Python 소스 (파일 이름의 `phase-01`은 기존 릴리스 스크립트·호환을 위해 유지)
- `drone-camera-android-v0.4.0-debug.apk`, `drone-camera-ios-v0.4.0-unsigned.ipa`, `drone-camera-ios-v0.4.0-xcode-project.zip`: 휴대폰 송출 앱 (`v0.4.0` 기준 빌드, 서명 전 IPA는 그대로 설치할 수 없으며 Xcode 프로젝트로 직접 설치)
- `SHA256SUMS.txt`: 데스크톱 및 모바일 첨부 파일 전체의 SHA256 체크섬

학습된 모델 파일(`best.pt`)은 첨부하지 않으며 프로그램의 **모델 불러오기**로 직접 선택합니다.

## 변경 내용 (`v0.6.0` 이후)

### 1. 카메라 지원 범위 비동기 조회 및 설정 자동 복구 (`probe.py`, `gui.py`, `usb.py`)
- **비동기 프로세스 조회 및 취소·타임아웃:** 카메라 지원 범위 조회(`Probe device`)를 별도 `spawn` 프로세스에서 수행하여 조회 중에도 GUI가 멈추지 않으며, 최대 30초 타임아웃과 입력 변경·설정창 닫기 시 즉시 취소 기능을 지원합니다.
- **휴대폰 USB 전달 경로 조회 및 EOF 처리:** 휴대폰 USB 연결 모드에서 지원 범위를 조회할 때 Wi-Fi 주소 대신 인증된 전용 USB 전달 경로를 사용하며, 로컬 전달기가 EOF 직전 응답을 잘라 버리지 않도록 수정했습니다.
- **재연결 완료까지 설정 자동 복구 감시:** 재연결 재시도가 8초를 넘기더라도 설정된 모든 재시도가 끝날 때까지 결과를 감시하여 연결 실패 시 직전 정상 설정으로 자동 복구합니다(사용자가 수동으로 연결을 해제하면 복구 감시 중지).

### 2. 체커보드 없는 자동 보정 및 상·하 카메라 배치 (`calibration.py`, `stereo_3d.py`, `dashboard_widgets.py`)
- **체커보드 없는 자동 보정:** 두 카메라가 겹쳐 보는 배경의 자연 특징점(`ORB + CLAHE + Lowe's Ratio + USAC_MAGSAC Essential Matrix`)을 매칭하여 체커보드 없이 상대 회전(`R`)과 이동 방향(`T`)을 자동 계산하는 기능과, 비행 중 드론 2D 궤적·기체 외관 크기를 이용해 기준선 거리(`baseline_m`)까지 자동 추정하는 기능을 추가했습니다.
- **상·하(위/아래) 및 좌·우 카메라 배치 지원:** 카메라 1(위)·카메라 2(아래) 수직 배치(`layout="vertical"`)와 좌·우 수평 배치(`layout="horizontal"`)를 모두 지원하며, 기체 크기 프리셋(`38.0 cm` / `25.1 cm`) 및 한쪽 카메라 가림 시 단안 크기 기반 3D 거리 추정 폴백 옵션을 제공합니다.

### 3. 릴리스 패키징 및 검증 강화 (`release.yml`, `test_release_workflow.py`)
- **모바일 송출 앱 첨부 및 누락 차단:** 릴리스 게시 워크플로에서 데스크톱 빌드(`Windows EXE/ZIP`, `macOS arm64/x64 DMG`, 소스 ZIP)와 함께 모바일 `v0.4.0` APK·서명 전 IPA·Xcode 프로젝트 및 SHA256 체크섬을 모두 포함하고, 필수 파일이 하나라도 누락되면 릴리스 게시를 중단합니다.

## 알아둘 점

- **검증 범위:** 카메라 비동기 조회·취소·타임아웃, USB 전달 조회, 설정 자동 복구, 체커보드 및 무체커보드 자동 보정, 상·하/좌·우 삼각측량, 다중 드론 대응·모호성 기각, 3D 충돌 위험 분석·판단 불가 상태, 데이터 기록·CSV·재생, 릴리스 워크플로 검증 등 총 214개 자동화 테스트(Linux/macOS/Windows CI) 및 동결 앱 스모크 테스트를 통과했습니다.
- **미검증 사항:** 실제 드론 2대 비행, 실외 환경 조명·배경에서의 탐지·삼각측량 정확도, 실제 무선/유선 카메라 간 촬영 시각 동기화 오차는 현장 실험에서 검증해야 합니다(`docs/stereo-3d-and-collision.md` 참고).
- **라이선스:** 자체 코드는 MIT이나, 번들된 Ultralytics(AGPL-3.0)로 인해 배포 바이너리에는 AGPL-3.0 조건이 적용될 수 있습니다.
