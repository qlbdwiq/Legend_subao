# macOS DMG (Apple Silicon and Intel)

기존 `v0.2.1` Windows EXE 릴리즈는 그대로 보존하며, 같은 1단계 기능을 macOS 앱으로도 제공합니다.
3D·AI·충돌 경고 등 2단계 이후 기능은 추가하지 않았습니다.

## 첨부 파일

- `DroneCollisionDetection-v0.3.0-macos-arm64.dmg`: Apple Silicon (M1 이상)
- `DroneCollisionDetection-v0.3.0-macos-x64.dmg`: Intel Mac
- `DroneCollisionDetection-v0.3.0-windows-x64.exe` / `.zip`: Windows 10/11 x64 (기존과 동일 기능)
- `phase-01-camera-stream-v0.3.0.zip`: 개발용 Python 소스
- `SHA256SUMS.txt`: 모든 배포 파일의 SHA256

DMG를 열어 앱을 Applications로 드래그하세요. 설치와 첫 실행 경고 해결은 `docs/macos-app.md`를 참고하세요.

## 알아둘 점

- macOS 앱은 **Developer ID 서명·Apple 공증이 되어 있지 않습니다**(ad-hoc 서명만). 처음 실행 시
  시스템 설정 > 개인정보 보호 및 보안 > "그래도 열기"가 필요할 수 있습니다. Gatekeeper를 우회하지 않습니다.
- Android USB용 `adb`(공식 Platform-Tools 37.0.1)가 내장되어 있습니다. iPhone USB, 카메라·로컬 네트워크 권한은 설명서를 참고하세요.
- CI에서 DMG를 마운트해 복사한 앱을 두 파일·두 MJPEG 입력으로 실행해 검증했습니다.
  **실제 Mac 사용자 환경, 실제 카메라, 실제 휴대폰 USB는 아직 검증하지 않았습니다.**
- Windows EXE는 Authenticode 서명이 없는 개발 배포본이라는 점이 기존과 같습니다.
