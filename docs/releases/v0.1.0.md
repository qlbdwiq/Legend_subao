# Phase 01 - Dual Camera Streaming

Drone Collision Detection System의 첫 단계로, 두 외부 카메라 영상을 동시에 수신·표시합니다.
객체 인식, 3D 위치 계산, 거리 계산, 충돌 경고는 아직 구현하지 않았습니다.

## 구현 기능

- HTTP(S) MJPEG, RTSP, USB 웹캠, 로컬 영상 입력 두 채널.
- 카메라별 연결·해제·수동 재연결, 유한 횟수 자동 재시도와 타임아웃.
- PySide6 다크 GUI, 영상 비율 유지, 실제 수신 FPS·해상도·상태·마지막 수신 시간.
- 프로세스별 수신과 한 장의 최신 프레임 버퍼, 수신 시각·프레임 번호 메타데이터.
- 설정 검증과 원자적 저장, 파일 반복 재생, 자원 해제, 합성 영상·오류·GUI 테스트.

## 지원 및 설치

Windows 10/11 x86-64와 macOS Apple Silicon/Intel을 대상으로 같은 Python 코드를 사용합니다.
Python 3.11 또는 3.12, CPU, 약 1GB 이상의 여유 메모리를 권장합니다. 실제 카메라·운영체제
장비 조합과 720p30 두 채널 성능은 별도 검증이 필요합니다.

소스 ZIP을 풀고 그 루트에서:

```powershell
# Windows PowerShell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r stages/01-camera-stream/requirements.txt
.\.venv\Scripts\python.exe stages/01-camera-stream/src/main.py
```

```bash
# macOS
python3.11 -m venv .venv
.venv/bin/python -m pip install -r stages/01-camera-stream/requirements.txt
.venv/bin/python stages/01-camera-stream/src/main.py
```

설정에서 두 입력을 지정하고 전체 연결을 누르세요. iPhone/iPad/Android는 별도의
스트리밍 앱에서 제공하는 직접 MJPEG/RTSP 주소를 사용합니다. 자세한 설명은 소스에 포함된
`stages/01-camera-stream/README.md`에 있습니다.

## 제한사항

- 첨부 ZIP은 **Python 소스 배포본**입니다. `.exe`나 `.app`, 영상, 개인 설정은 포함하지 않습니다.
- 장치 기본 카메라 앱·WebRTC·HLS·DRM 영상·브라우저 페이지 입력은 지원하지 않습니다.
- FFmpeg/OpenCV의 네트워크 지연이나 USB 드라이버 특성에 따라 실제 지연이 달라집니다.
- 네이티브 백엔드가 멈추면 watchdog이 프로세스를 종료하고 수동 재연결을 요구할 수 있습니다.
- 4K BGR 프레임 한 장 크기(3840×2160×3 바이트)가 최대 버퍼입니다. GPU 의존성은 없습니다.
- 촬영 시각 동기화·인식·3D·위험 판단·녹화 기능은 없습니다.

다음 단계는 YOLO 드론 인식·추적이며, 이후 스테레오 보정과 3D 추적, 충돌 경고, 대시보드 순으로 개발합니다.
