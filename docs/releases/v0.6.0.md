# Stereo 3D Tracking, Collision Risk Warning & Mission Control Dashboard

기존 1단계(두 카메라 실시간 수신·표시, 모바일 앱 Wi-Fi/USB 연동)와 2단계(YOLO11n 드론 탐지·ByteTrack 추적·바운딩 서클)를 모두 유지하면서,
**3단계(스테레오 카메라 보정·3차원 좌표 계산)**, **4단계(3D 충돌 위험 분석·경고)**, **5단계(통합 관제 대시보드·실험 기록·CSV 내보내기·재생)**를
하나의 완성된 프로그램으로 통합합니다. 기존 `v0.1.0`–`v0.4.0` 및 `phase-02-v0.5.0` 태그와 릴리스는 그대로 보존됩니다.

> **실험용 / 실제 비행 미검증 안내**
> - 이 릴리스의 3~5단계 기능은 단위 테스트, 알려진 카메라 배치·정답 좌표를 갖는 합성 데이터, 헤드리스 GUI 통합 테스트 및 GitHub Actions CI(Windows·macOS)로 검증되었습니다.
> - **실제 드론 2대 비행, 실외 환경에서의 스테레오 보정, 실제 비행 중 위치 오차 및 충돌 경고 성능은 아직 현장 실험 전(미검증)입니다.**
> - 본 프로그램은 실험용 보조 시스템이며 실제 비행 안전을 보장하지 않고 드론 자동 제어 기능을 포함하지 않습니다.

## 첨부 파일

- `DroneCollisionDetection-v0.6.0-macos-arm64.dmg`: Apple Silicon (M1 이상)
- `DroneCollisionDetection-v0.6.0-macos-x64.dmg`: Intel Mac
- `DroneCollisionDetection-v0.6.0-windows-x64.exe` / `.zip`: Windows 10/11 x64 (CPU 전용 AI)
- `phase-01-camera-stream-v0.6.0.zip`: 개발용 Python 소스 (파일 이름의 `phase-01`은 기존 릴리스 스크립트·호환을 위해 유지)
- `SHA256SUMS.txt`: 첨부 파일의 SHA256

학습된 모델 파일(`best.pt`)은 첨부하지 않으며 프로그램의 **모델 불러오기**로 직접 선택합니다.

## 변경 내용

### 3단계 — 실시간 3차원 좌표 계산 (`calibration.py`, `stereo_3d.py`)
- **카메라 내부·외부 보정 및 왜곡 보정:** 체커보드 코너 검출(`cv2.findChessboardCornersSB`), 단일 카메라 내부 파라미터·왜곡 계수 보정(`cv2.calibrateCamera`), 스테레오 상대 회전(`R`)·이동(`T`) 보정(`cv2.stereoCalibrate`), 기준선 길이(`baseline_m`) 설정 및 `stereo_calibration.json` 저장·불러오기를 지원합니다.
- **프레임 시간 동기화 및 속도 보간:** 두 카메라 프레임의 시간 차이($\Delta t$)와 시계 오프셋(`time_offset_s`)을 측정·보정하고, 허용 오차(`max_sync_delta_s`) 초과 시 동기화 불량으로 판정합니다.
- **카메라 간 드론 대응 및 모호성 기각:** 카메라 1과 카메라 2의 ByteTrack ID가 같다고 가정하지 않고 에피폴라 기하(Sampson 거리)와 재투영 오차로 대응시킵니다. 다중 드론에서 대응이 모호하면 좌표를 확정하지 않고 `ambiguous_match`로 기각합니다.
- **스테레오 삼각측량 및 신뢰도 지표:** 미터(`m`) 단위의 3D 좌표 $(X, Y, Z)$, 좌·우 재투영 오차(px), 위치 불확실성($\pm\text{m}$), 신뢰도 점수를 계산합니다.
- **미보정 시 가짜 좌표 출력 금지:** 보정 데이터가 없으면 3D 좌표를 생성하지 않으며 `실제 보정`과 `합성/테스트 보정` 상태를 명확히 구분해 표시합니다.

### 4단계 — 충돌 위험 분석 (`collision.py`)
- **3D 거리·속도·CPA 분석:** 두 드론의 3D 직선 거리, 위치 불확실성을 차감한 보수적 유효 거리, 시간에 따른 3D 속도 벡터·이동 방향, 상대 접근 속도, 예측 시간(`prediction_horizon_s`) 내 예상 최근접 거리(`d_cpa_m`)와 최근접 시점(`t_cpa_s`)을 계산합니다.
- **위험 단계 및 판단 불가(`UNKNOWN`) 처리:** 설정 가능한 주의/위험 거리·접근 속도 임계값(`collision_settings.json`)에 따라 `안전(SAFE)`, `주의(CAUTION)`, `위험(DANGER)`을 판정합니다. **미보정, 동기화 불량, 대응 모호, 2대 미만 추적 시에는 절대 '안전'으로 표시하지 않고 '판단 불가(UNKNOWN)'로 처리합니다.**
- **시각·청각 경고 및 이벤트 로그:** 위험 단계별 배너 색상·문구, 쿨다운이 적용된 청각 경고(비프음), 위험 단계 전이 이벤트(`RiskEvent`) 기록을 제공합니다. 2D 바운딩 서클 반지름(px)은 화면 표시 전용이며 3D 안전거리 판단에 사용하지 않습니다.

### 5단계 — 관제 대시보드 및 실험 기록 (`gui.py`, `dashboard_widgets.py`, `recorder.py`)
- **3구역 관제 대시보드:** 좌측(카메라 1·2 실시간 영상 + 2D 오버레이), 중앙(위험 배너 + 3D 공간 시각화 `Top X-Z / Front X-Y / 3D Iso` + 드론별 3D 텔레메트리), 우측(2D AI 설정 + 3D 보정·임계값 + 실험 기록·CSV·재생)으로 구성했습니다.
- **스테레오 보정 마법사(`CalibrationWizardDialog`):** 실시간 카메라 체커보드 캡처·보정, 기준선·시간 오프셋 설정, 합성 보정 프리셋 생성, JSON 내보내기·불러오기를 지원합니다.
- **실험 기록·CSV 내보내기·재생(`ExperimentRecorder`, `PlaybackDialog`):** 세션별 `telemetry.jsonl`, 스테레오 합성 영상(`stereo_video.avi`), 프레임별 `telemetry.csv`, `risk_events.csv` 저장 및 타임라인 슬라이더 재생·통계 분석 창을 제공합니다.

## 알아둘 점

- **검증 범위:** 카메라 보정 수치 정확성, 합성 좌표 삼각측량 오차, 카메라 간 대응·모호성 기각, 프레임 동기화 오류, 다중 드론 3D 거리·상대 속도·CPA·경고·판단 불가 상태, 데이터 기록·CSV·재생, 헤드리스 GUI 회귀 테스트(총 196개 자동화 테스트) 및 GitHub Actions Windows EXE·macOS arm64/Intel DMG 스모크 테스트를 통과했습니다.
- **미검증 사항:** 실제 드론 2대 비행, 실외 환경 조명·배경에서의 탐지·삼각측량 정확도, 실제 무선/유선 카메라 간 촬영 시각 동기화 오차는 현장 실험에서 검증해야 합니다(`docs/stereo-3d-and-collision.md` 참고).
- **라이선스:** 자체 코드는 MIT이나, 번들된 Ultralytics(AGPL-3.0)로 인해 배포 바이너리에는 AGPL-3.0 조건이 적용될 수 있습니다.
