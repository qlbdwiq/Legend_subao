# Mobile Cameras - Wi-Fi and USB

기존 두 카메라 수신기에 자체 Android/Galaxy 및 iPhone/iPad 송출 앱과 USB 연결을 추가했습니다.
기존 `v0.1.0` 릴리즈와 1단계 결과물은 보존합니다. YOLO·3D·충돌 경고는 구현하지 않습니다.

## 첨부 파일과 설치

- **Android**: `drone-camera-android-v0.2.0-debug.apk` — 설치 가능한 개발용 서명 APK, Android 8.0+.
- **iPhone**: `drone-camera-ios-v0.2.0-xcode-project.zip` — Mac에서 Xcode로 열고 무료 Apple 계정의
  Personal Team을 선택한 후 실제 iPhone에 Run하여 설치합니다. iOS 16+.
- `drone-camera-ios-v0.2.0-unsigned.ipa` — 실제 iPhone arm64 빌드의 **서명 전 IPA이며 그대로 설치할 수 없습니다.**
  Apple 서명·프로비저닝을 우회하지 않습니다. 무료 계정 사용자는 위 Xcode 프로젝트로 직접 설치하세요.
- `phase-01-camera-stream-v0.2.0.zip` — Windows/macOS 데스크톱 Python 3.11/3.12 소스 배포본.
  가상환경 생성 후 `python -m pip install -r stages/01-camera-stream/requirements.txt`,
  `python stages/01-camera-stream/src/main.py`로 실행합니다. `.exe`·`.app`은 포함하지 않습니다.

전체 설치·연결 절차는 저장소 `docs/mobile/README.md`에 있습니다.

## 기능

- 후면 카메라를 최대 720p / 30fps (15fps 선택 가능) 목표의 인증된 MJPEG로 송출, 미리보기·시작/중지·URL 복사.
- 동일 Wi-Fi에서 연결, 또는 Wi-Fi 없이 USB 연결. 두 휴대폰과 유선/무선을 혼합할 수 있습니다.
- Android USB: 공식 Platform-Tools `adb`, USB 디버깅 승인 필요.
- iPhone USB: macOS USB 서비스 또는 Windows Apple Mobile Device 드라이버/서비스, 신뢰 승인 필요.
- 데스크톱 USB 도우미와 설정 저장, 임시 로컬 포트 자동 생성, 연결 오류 안내와 자원 정리.
- 휴대폰 송출 중지는 백그라운드/잠금 시에도 적용하며, 같은 앱 세션의 중지·재시작에서는 URL을 유지합니다.

## 검증 범위와 제한

CI는 Windows/macOS 데스크톱 테스트, Android APK·개발 서명·Java 단위 테스트·lint,
실제 Java 서버 → OpenCV 프로토콜 통합, iOS 시뮬레이터 Swift 테스트 및 device arm64 빌드를 수행합니다.
물리 카메라, USB 케이블·드라이버·신뢰, 장시간 성능은 별도 실장비 검증이 필요합니다.

무료 Apple 서명은 Apple의 유효기간·기기 제한을 따르며 만료되면 Xcode에서 다시 설치해야 합니다.
APK는 CI 개발 키이므로 다른 빌드와 서명이 다르면 기존 앱 삭제 후 설치가 필요합니다.
앱 완전 종료/재생성 또는 Wi-Fi IP 변경 시 연결 URL을 갱신하세요. HTTP 송출은 신뢰하는 LAN/USB용이며
인터넷 공개용이 아닙니다. 수신 시각은 촬영 시각이 아니고 두 카메라의 시각을 동기화하지 않습니다.

다음 개발 단계는 YOLO 드론 인식·추적이며 이번 릴리즈에 임의로 추가하지 않았습니다.
