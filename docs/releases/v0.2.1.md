# Windows Standalone EXE

Python을 따로 설치하지 않아도 실행되는 **Windows 10/11 x86-64 데스크톱 EXE**를 제공합니다.
기존 두 카메라 수신·Wi-Fi·Android/iPhone USB 연결 기능을 유지합니다.

## 다운로드 및 실행

- `DroneCollisionDetection-v0.2.1-windows-x64.exe`: 내려받아 더블클릭. Python·pip·OpenCV·PySide6 별도 설치 불필요.
- `DroneCollisionDetection-v0.2.1-windows-x64.zip`: 같은 EXE, 설정 예제, 설명서, 라이선스를 포함한 압축본.
- `phase-01-camera-stream-v0.2.1.zip`: 개발용 Python 소스.
- `SHA256SUMS.txt`: EXE와 압축본의 SHA256.

설정에서 휴대폰 연결 URL을 입력한 뒤 연결하세요. 유선은 **USB 연결 도우미**를 사용합니다.
Android용 adb는 내장되어 별도 Platform-Tools 설치가 필요 없습니다. USB 기기 드라이버·디버깅/신뢰 승인은 필요합니다.
iPhone USB의 Windows Apple Mobile Device 서비스도 별도로 준비되어 있어야 합니다.

모바일 앱은 [v0.2.0](https://github.com/qlbdwiq/Legend_subao/releases/tag/v0.2.0)의 APK와 Xcode 프로젝트를 그대로 사용합니다.
iPhone의 기존 서명 전 IPA는 직접 설치할 수 없으며 무료 Apple 계정 사용자는 Xcode Personal Team으로 설치합니다.

## 검증

Windows CI에서 단일 EXE를 한글·공백 폴더에 복사하고 Python·SDK PATH를 제거한 상태로 실행합니다.
Qt Windows GUI, 실제 두 파일·두 MJPEG 입력, FPS·프레임 표시, 프로세스 정리, 내장 adb 실행을 검사합니다.
기존 Windows/macOS·모바일 CI도 유지합니다. 실제 카메라·USB 하드웨어 성능은 별도 검증이 필요합니다.

EXE는 Windows 게시자 인증서로 서명되지 않은 개발 배포본입니다. 기업 정책/백신 차단을 우회하지 않습니다.
macOS `.app`은 이번 변경에 포함하지 않았으며 기존 소스 실행을 유지합니다. 3D·AI·충돌 경고 기능은 추가하지 않습니다.
