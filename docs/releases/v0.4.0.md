# Camera resolution and FPS expansion

기존 `v0.3.0` Windows EXE·macOS DMG 릴리즈는 그대로 보존하며, 같은 1단계 두 카메라
수신 기능에서 스마트폰 카메라가 실시간 스트리밍으로 실제 지원하는 해상도·FPS까지
선택할 수 있도록 확장합니다. 3D·AI·충돌 경고 등 2단계 이후 기능은 추가하지 않았습니다.

## 첨부 파일

- `DroneCollisionDetection-v0.4.0-macos-arm64.dmg`: Apple Silicon (M1 이상)
- `DroneCollisionDetection-v0.4.0-macos-x64.dmg`: Intel Mac
- `DroneCollisionDetection-v0.4.0-windows-x64.exe` / `.zip`: Windows 10/11 x64
- `phase-01-camera-stream-v0.4.0.zip`: 개발용 Python 소스
- `SHA256SUMS.txt`: 모든 배포 파일의 SHA256

## 변경 내용

- Android는 Camera2 실시간 YUV 스트림 형식에서, iPhone은 AVFoundation 데이터 출력
  형식에서 해상도별 최대 FPS를 열거합니다. 일반 동영상 녹화 프로필은 사용하지 않습니다.
- 휴대폰 앱에서 전면·후면, 해상도, FPS를 직접 선택합니다. 기본값은 발열·대역폭을
  고려한 720p·30 FPS이며, 기기가 지원하면 1080p·1440p·4K와 60/120/240 FPS도 선택할 수 있습니다.
- 휴대폰은 인증이 필요한 `/capabilities` 응답으로 지원 조합을 데스크톱에 제공합니다.
  데스크톱 설정의 **지원 범위 확인**은 그 목록만 메뉴에 남겨 지원하지 않는 조합을 막습니다.
- 데스크톱은 카메라마다 해상도·FPS·방향을 독립 저장합니다. USB 웹캠에는 요청값을
  실제 적용하고, 휴대폰 스트림에는 설정값·백엔드 캡처 FPS·실측 수신 FPS·실제 해상도를
  구분해 표시합니다. 설정값만 높게 표시하지 않습니다.
- 연결 중 설정을 바꾸면 자동으로 다시 연결하고, 새 설정이 오류로 끝나면 이전에
  정상 작동하던 설정으로 복구합니다.
- 데스크톱 수신 버퍼 한계는 기존과 같은 3840×2160입니다. 그보다 큰 센서 해상도는
  실시간 MJPEG 파이프라인 범위를 벗어나므로 지원 목록에서 제외해 알립니다.

## 알아둘 점

- 고해상도·고FPS MJPEG는 대역폭·CPU·발열 부담이 큽니다. 두 대 동시 사용 시 실제
  수신 FPS가 설정값보다 낮아질 수 있으며, 화면의 실측값이 최종 기준입니다.
- CI에서 파일·MJPEG 합성 입력으로 검증했습니다. **실제 휴대폰의 4K/120/240 FPS
  스트리밍, 장시간 발열, Wi-Fi 대역폭은 실장비 검증이 아직 필요합니다.**
- macOS 앱은 Developer ID 서명·Apple 공증이 되어 있지 않고, Windows EXE는
  Authenticode 서명이 없는 개발 배포본이라는 점이 기존과 같습니다.
- 모바일 APK·서명 전 IPA·Xcode 프로젝트는 `v0.2.0` 배포본을 그대로 사용합니다.
